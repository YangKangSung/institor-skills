# Keyword packs (KR malls)

Short tokens for Naver Shopping / Coupang-style search. Extend per case; don’t dump essays into the search box.

## Pack: door/window power pass

**Use when:** feed power across a closed door/window with draft control.

| Priority | Query |
|----------|--------|
| 1 | `강제환기 전용 문풍지` |
| 2 | `문풍지` / `창문 틈새막이` |
| 3 | `연장선 15A` / `고용량 연장선` (length short) |
| 4 | `창문형 에어컨 패널` (optional panel) |
| 5 | `전선 몰딩` / `바닥 전선 커버` |

**Avoid for microwave-tier+:** `초슬림 문틈 전선`, no-amp ribbon cords, daisy-chained cheap strips.

## Pack: general extension

| Query | Note |
|-------|------|
| `연장선 15A` | Prefer rated amps on listing |
| `과부하차단 멀티탭` | Short strip at far end |
| `접지 연장선` | When gear has earth pin |

## Pack: fit / wearables

Prefer geometry language (mm, lug, model). Generic `전모델호환` titles are weak evidence.

Delegate deep Galaxy lug matrices to operator fit notes when available; public skill stays class-level.

## Pack: avoid noise

- Long blog-style questions in shopping search  
- Mixing brand rant + product token  
- Searching only English for KR-only SKUs when Korean tokens exist
