# Keyword packs

Short tokens for **any** shop search box. Keep both the scene language and a short English twin when it helps.

## Pack: door/window power pass

**Use:** feed power across a closed door/window; control draft.

| Priority | Query |
|----------|--------|
| 1 | `강제환기 전용 문풍지` · `door weatherstrip cable pass` |
| 2 | `문풍지` · `창문 틈새막이` |
| 3 | `연장선 15A` · `15A extension cord` (prefer short) |
| 4 | `케이블 그로밋` · `cable grommet` · `floor cord cover` |

**Avoid (microwave-tier+):** `초슬림 문틈 전선`, unrated ribbon, daisy-chained thin strips.

## Pack: fit / wearables

Use model + mm + adapter language. Weak: bare `전모델호환` / `universal fit`.

## Pack: avoid noise

- Long blog questions in the search box
- Mall name + rant in the same query
- Mixing rant text with product tokens
