# Keyword packs (KR malls + general)

Short tokens for Naver Shopping / Coupang-style search.

## Pack: door/window power pass

**Use:** feed power across a closed door/window; control draft.

| Priority | Query |
|----------|--------|
| 1 | `강제환기 전용 문풍지` |
| 2 | `문풍지` · `창문 틈새막이` · `문틈 막이` |
| 3 | `연장선 15A` · `고용량 연장선` (prefer short length) |
| 4 | `창문형 에어컨 패널` · `창에어컨 가림판` |
| 5 | `전선 몰딩` · `바닥 전선 커버` · `코드 커버` |
| 6 | `케이블 그로밋` · `전선 통과 고무` (panel hole) |

**Avoid (microwave-tier+):** `초슬림 문틈 전선`, unrated ribbon, daisy-chained thin strips.
