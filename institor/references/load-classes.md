# Load classes

Use one label in the verdict block.

| Class | Rough band (single-phase ~220–240V) | Cord / strip | Door/window pass |
|-------|-------------------------------------|--------------|------------------|
| **light** | &lt; ~300 W (LED, fan, phone, laptop brick) | Ordinary extension OK | Flat/weatherstrip pass OK if not crushed |
| **microwave-tier** | ~1.0–1.5 kW (~5–7 A @ 220V) | **10–15A** rated, **short**, uncoil reels fully; no other heater on same strip | Pass without pinching insulation; no ultra-slim “gadget only” ribbon as sole feed |
| **heavy** | dryer-class, multi-kW heater, continuous high draw | Dedicated circuit / thick cable / pro work — **out of casual shopping scope** | Do not “solve” with door-gap shopping tips alone |

## Rules

1. Concurrent loads **add**. Two microwave-tier devices ≈ heavy territory on one outlet.
2. Warm plug or strip → stop.  
3. Reels: fully unwind under microwave-tier+.  
4. Wet / solvent / outdoor drip → elevate connections; prefer RCD/GFCI where local code expects it.  
5. This table is **research guidance**, not an electrical code certificate.

|-----------|---------------|
