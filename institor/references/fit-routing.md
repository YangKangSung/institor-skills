# Fit routing

Public Institor stays **class-level**. Deep device matrices may live in a thicker operator skill; still follow this route so answers stay honest.

## Steps

1. **Name the device** (exact model if possible).  
2. **Direction of fit** — accessory → device, or device-side adapter → third-party strap/part.  
3. **Options on the listing** — mm, color, “전용 모델” text.  
4. If user pastes **order/myshop**: every line including **사은품**. Gift adapters often target a *different* model family than the main SKU.  
5. OEM constraint in one sentence (e.g. proprietary lug vs spring-bar mm).  
6. Cross-check product **class** (not one 5-star).  
7. Verdict label: OK / conditional / unverified seller / no.

## Wearable mm (strap width)

| Option | Typical |
|--------|---------|
| 20mm | Many general smartwatch spring-bar straps |
| 22mm | Larger cases / some leather-metal |
| 24mm | Wide outdoor/custom — only if strap **and** adapter are 24 |

mm is **strap-side** span, not case diameter marketing numbers.

## Don’t

- Trust “전모델호환” titles alone  
- Assume gift adapter matches the watch you own  
- Re-lecture full lug essays when user only asked “22 or 24 strap?” — answer the number first  

## Output

Verdict line first, then 1–3 geometry bullets, then buy/fix keywords if still shopping.
