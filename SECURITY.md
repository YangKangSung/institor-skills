# Security

## Report

Open a GitHub issue with the `security` label, or contact the maintainer via GitHub.

Do **not** open a public issue for live credentials.

## Project rules

- No API keys, tokens, cookies, or `.env` values in git.
- No personal emails in commits (`users.noreply.github.com` only).
- No real order IDs, card data, addresses, or phone numbers in samples.
- No host-absolute paths (`C:\Users\…`, `/home/…`) in public tree.
- Samples are **synthetic** or generic DIY scenes only.

## Agent use

Institor helps research purchases. It does **not** automate checkout, payment, or account takeover.
